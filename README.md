# QuestWow — аддон для WoW Forever

Цепочки квестов: свои и друга, квесты по зонам, синхронизация и быстрые линки в чат.

## Установка (у тебя и у друга)
1. Скачай `QuestWow-x.y.z.zip` со страницы [Releases](https://github.com/levkastergit/questwow/releases)
   и распакуй его в `Interface\AddOns` клиента WoW Forever. Должна получиться папка `Interface\AddOns\QuestWow`.
2. Добавь друга одним из способов:
   - `/qw add Имя Фамилия` — в WoW Forever у персонажей есть фамилия, она обязательна;
   - кнопка **«+ Добавить друга»** в окне: выбор из группы или рейда, цели или списка друзей в сети.

   Друг делает то же самое с тобой.
3. Если аддон в списке помечен как «устаревший», выполни в чате `/dump select(4, GetBuildInfo())`.
   Подставь полученное число в строку `## Interface:` файла `QuestWow.toc`.

## Возможности
- **Лента** — все сданные квесты (твои и друга) по времени: зона, уровень, кто сдал.
- **Цепочки** — прогресс каждого игрока и шаги с отметками.
  Фильтр скрывает пройденные цепочки: пройденные тобой или всеми показанными игроками.
  Кнопки: «Линк цепочки в чат», «Мой следующий квест», «Где друг?».
- **Зоны** — континенты, а в них зоны. Для каждой зоны:
  - квесты: все, только те, что ты ещё не сделал, или те, что можно взять прямо сейчас;
  - цепочки зоны;
  - прогресс каждого игрока.

  Кнопка «Моя текущая зона».
  Если установлен **Questie**, в зонах показаны все квесты из его базы, включая те, что вы ещё не брали:
  уровень квеста, значок «!» у квестов, которые можно взять сейчас, и пометки «с 30 ур.», «до 40 ур.» или «нужен пред. квест».
  Режим «Можно взять» учитывает уровень персонажа (`requiredLevel` / `requiredMaxLevel` из базы Questie) и предыдущие квесты.
- **Сравнение** — квесты, которые есть только у тебя, только у друга или у обоих.
  Тумблер «Скрыть классовые квесты» убирает квесты для отдельных классов (`requiredClasses` из базы Questie).
- Уровень квеста `[12]` стоит перед названием везде: в ленте, цепочках, зонах и сравнении.
  Цвет показывает сложность относительно твоего уровня, как в журнале квестов. У цепочек виден диапазон уровней `[10-14]`.
- **ЛКМ** по квесту — линк в чат, **ПКМ** — открыть его цепочку.
- Уведомление в чате, когда друг сдаёт квест (если вы оба в сети).
- Кнопка у миникарты: ЛКМ — окно, ПКМ — настройки.
  Перетаскивание двигает кнопку по кругу, Shift + перетаскивание — в любое место экрана.

## Команды
| Команда | Что делает |
|---|---|
| `/qw` | открыть или закрыть окно |
| `/qw add Имя Фамилия` | добавить друга |
| `/qw del Имя Фамилия` | удалить друга |
| `/qw sync` | синхронизировать вручную |
| `/qw link ID` | линк квеста в чат |
| `/qw chain ID` | открыть цепочку квеста |
| `/qw zone [название]` | квесты зоны; без названия — текущая зона |
| `/qw minimap` | показать или скрыть кнопку у миникарты |
| `/qw minimap reset` | вернуть кнопку на место |

## Откуда данные
- **Выполненные квесты** — `C_QuestLog.GetAllCompletedQuestIDs()` и событие `QUEST_TURNED_IN`.
  Время, зона и уровень записываются только для квестов, сданных с установленным аддоном.
- **Цепочки** — API клиента `C_QuestLine`. Если установлен аддон **Questie**, добавляется его база
  (`preQuestSingle` / `nextQuestInChain`).
- **Зона квеста** — проверяется по порядку:
  1. заголовок журнала квестов, под которым квест был;
  2. база Questie;
  3. карта, на которой квест сдан.
- **Имена** — в WoW Forever `UnitName()` возвращает имя и фамилию, и шёпот адресуется как «Имя Фамилия».
  Источник: наблюдения автора аддона [bff-wow, PR #152](https://github.com/Shtian/bff-wow/pull/152).
- **Синхронизация** — скрытые аддон-сообщения (`C_ChatInfo.SendAddonMessage`, канал WHISPER).
  Оба игрока должны быть в сети. Пробные аккаунты не могут отправлять аддон-сообщения.
